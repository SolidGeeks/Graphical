# Solid Geeks logo kit

The Solid Geeks logo, in every version and size, with the rules for using it. Read the **[usage guide](GUIDE.md)** first: colours, clear space, minimum sizes and don'ts.

| Folder | What is in it |
|---|---|
| `svg/` | The masters, in vector: horizontal, stacked, symbol only, name only, and a pixel-drawn small-size symbol, most of them in several colour versions (dark, ink, black, white, Volt) |
| `png/` | Ready-to-use exports: the avatar (1024 px), the GitHub social preview (1280 × 640), README logos |
| `web/` | Everything a website needs: favicons, app icons, `site.webmanifest`, and `head-snippet.html` to paste into the `<head>` |
| `presentation/` | The presentation board of the final identity (`board.html`) and its slides |

## Quick picks

- **GitHub or Discord avatar:** `png/sg-avatar-1024.png`, made to survive the round crop
- **A README, light and dark:** the `<picture>` snippet at the top of this file, with `svg/sg-readme-light.svg` and `svg/sg-readme-dark.svg`
- **A website:** copy `web/` next to the page and paste `web/head-snippet.html` into its `<head>`
- **Below 32 px:** `svg/sg-symbol-small.svg`, drawn pixel by pixel for small sizes

Colours: **Volt** `#C8FF2E` and **Ink** `#0D0F0C`. Never Volt on white.
